# Mesh Segmentation

Open **Workspace → Segment** at `/workspace/segment`. Select a mesh or upload one, choose an available segmentation model, set the desired part count, and choose the segmentation method.

## Methods and options

- **Semantic** uses part meaning as the goal when the selected model supports it.
- **Geometric** emphasizes geometry-based separation.
- **Hierarchical** builds a nested part structure when enabled.
- **Target Parts** is a requested count, not a guarantee; model capability and mesh structure can affect the returned number of parts.
- Post-processing options include minimum part face count, smoothing, maximum hierarchy depth, part hints, symmetry, watertight repair and convex decomposition. Only options forwarded by the active request/backend contract take effect.

## Before using the result

The panel checks feature availability and model readiness before queueing. Inspect the generated parts, labels and task report after completion. Small or tightly connected features may not separate exactly as requested, and any optional repair/decomposition stage can fail independently.
