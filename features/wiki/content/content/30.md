# Auto Retopology

Open **Workspace → Poly** at `/workspace/remesh`. Choose a mesh asset or upload a supported mesh, select the target topology and target poly-count budget, then run the remesh operation.

## Main choices

- **Triangles / Quads** selects the intended output topology. A successful request does not guarantee a quad-dominant result if the retopology stage reports a failure or degraded output.
- **V1K / V4K** selects the available processing variant shown by the panel.
- **Target Poly Count** is a geometry budget, not a model-inference setting. Extremely low budgets can remove silhouette or deformation detail.

## Verify output

Inspect the result mesh, face count and reported task status. Review the source and result side by side before using the new topology for rigging, baking or export. When the pipeline reports a failure or degraded stage, do not treat the selected topology as proof of the final mesh's actual topology.
