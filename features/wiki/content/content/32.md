# Auto Rigging

Open **Workspace → Rigging** at `/workspace/rigging` and select the character mesh to rig.

## UniRig AI

The active auto-rigging action submits the mesh to the UniRig backend and returns a skinned GLB when successful. The current adapter uses its native biped topology and model-default weights. Custom skeleton presets, IK generation and arbitrary weight overrides are not supported by this adapter.

Advanced controls should be treated as effective only where the active backend contract accepts them. Check the resulting job state and confirm that the output includes a skeleton and skin weights before sending the asset into animation or export.

## Manual armature

The panel distinguishes the Manual Armature path from UniRig AI. Selecting Manual Armature does not run the UniRig inference request; the manual route is a separate editing workflow. Do not interpret a mode change alone as a generated rig.
