# Auto UV Unwrapping

Open **Workspace → UV** at `/workspace/uv`. Select a mesh from Assets or upload a supported 3D file, then run the PartUV UV pipeline.

## Before running

- Choose a mesh asset rather than an image or texture asset.
- Inspect the mesh and material state first. UV unwrapping generates or revises UV coordinates; it does not generate a texture by itself.
- The current workspace action requests the Blender packing method, a distortion threshold of 1.25 and GLB output by default.

## After running

Review the returned job state and resulting mesh before baking or painting textures. Highly overlapping geometry, malformed input, or backend/dependency errors can prevent a usable result. Keep a copy of the source asset when comparing UV layouts.

For lower-level UV options, see `features/utils/meshTools.js` and the backend UV-unwrapping router.
