# Texturing

Open **Workspace → Texture** at `/workspace/texture` and select a mesh asset to texture. A valid mesh with usable UVs is the safest starting point for predictable texture baking and map output.

## Model and resolution

- The active Texture panel discovers model readiness through the backend's model inventory; a model may appear unavailable when its weights are missing.
- The current request path uses Paint3D for 1K/2K atlas outputs and Hunyuan3D-Paint for 4K/8K outputs.
- Atlas resolution is a production output setting, separate from the numerical inference profile owned by the model adapter.
- Supply a reference image or text prompt only when the selected model supports that input type. The panel validates the required reference input before queueing.
- PBR map generation is part of the texturing request when enabled; the final maps depend on the selected model and backend stage completing successfully.

## Validate the result

Check the generated job result and material maps rather than assuming the request alone guarantees a successful bake. UV quality, input/reference compatibility, installed weights and memory constraints can affect the outcome.
